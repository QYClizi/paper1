**先读 [`项目总览.md`](项目总览.md)。** 那份文件在五分钟内讲清整个项目；本文件只是文件夹的使用说明。

## 使用规则

1. **单一真相源**。数值只写在 `experiment_space.yaml`；门的阈值只写在 `pilot_protocol_v0.2.md` 和 YAML。其他文件一律用 `yaml: 键路径` 引用，**代码不得从 md 抄数字**。
2. **每个事实只住在一个文件里**。写文档前先问"这属于规范、理由、符号、单位、数值还是门"，然后只在那一个文件里写。
3. **不静默修改**。改动任何冻结数值或规则，必须新建版本并在 `decisions.md` 记录理由和生效边界。需要新版本的事项清单见 `scope.md` 附录 B。
4. **不为让 AI 获胜而改题**。用户数、物理参考参数和正式 split 在 Pilot-A 前不因期望结果而改动；只有 Pilot-A 可以触发版本化的生成分布修订；**不得在查看正式 test/OOD 后调参**。
5. **优先最简实现**。在具有现实解释和研究意义的前提下，优先采用实现最简单、开发速度最快的方案。
6. **SCIP 始终负责**可行性、界、剪枝与最优性声明；不改成由纯 AI 直接替代求解器。

## 当前执行顺序

```
1. 生成器 + 强化缩放 MILP + 默认 SCIP baseline + A0 前置门
2. Pilot-A：A0 → A1/A2 → A5-headroom → 判门 1/3/6
              → A3 候选映射 → A4 教师接口 → 判门 2/5/7
              → A5-shadow → 判门 4 → A6 决定
3. 仅 GO 才生成正式标签并训练三个种子
4. checkpoint 选择并冻结 manifest
5. 用实际入选 checkpoint 执行 Pilot-B
6. 锁定全部哈希后运行 ID test 与 OOD
```

详见 `pilot_protocol_v0.2.md`。
