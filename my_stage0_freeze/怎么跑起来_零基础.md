# 怎么把脚本跑起来（零基础，Windows）

> 全程约 10 分钟，其中 8 分钟是等下载。
> **不需要任何编程基础，不需要打命令。**

---

## 最省事的办法：双击 `跑我.bat`

在你的项目文件夹里找到 **`跑我.bat`**，**双击它**。

会弹出一个黑色窗口，自动做三件事：

1. 检查 Python 装没装
2. 检查 pyscipopt 装没装，没装就自动装
3. 运行脚本，把结果打出来

**如果一路顺利，你会看到类似这样的东西：**

```
============================================================
  第 1 步 / 共 3 步  检查 Python 有没有装
============================================================
Python 3.12.4
  [OK] Python 找到了

============================================================
  第 2 步 / 共 3 步  检查 pyscipopt 有没有装
============================================================
   [OK] pyscipopt 6.2.1

============================================================
  第 3 步 / 共 3 步  开始运行
============================================================

题目：12 个物品，两个容量限制，最大化总价值
（presolve / 割平面 / 启发式 全部关掉，只留主循环）

================================================================
第 1 次被调用   |   节点编号 1   深度 0
----------------------------------------------------------------
① 挑节点   : SCIP 挑了 1 号节点（待办清单里还剩 0 个）
② 解松弛   : 本节点 LP 目标值 = -132.0175
             ...
```

**看到这个就成了。往上滚动能看到全部内容。**

## 如果第 1 步就报错：没有 Python

窗口会告诉你 `[失败] 没有找到 Python`。按下面做：

### ① 下载

打开浏览器，访问 **https://www.python.org/downloads/**

页面最上方有个大黄按钮，写着 **"Download Python 3.x.x"**，点它。会下载一个 `.exe` 文件。

### ② 安装（★ 这一步有个坑，务必注意）

双击刚下载的 `.exe`。

**安装窗口最下面有一个复选框：**

```
☐  Add python.exe to PATH
```

**必须勾上它。**

这是新手第一名的翻车点。不勾的话，Windows 找不到 Python，后面全部报错。

勾上之后，点 **"Install Now"**，等它装完（约 2 分钟）。

### ③ 重启电脑

装完**重启一次**。不重启的话有时 PATH 不生效。

### ④ 回去重新双击 `跑我.bat`

---

## 如果第 2 步报错：pyscipopt 装不上

窗口会提示 `[失败] pyscipopt 安装失败`。三种常见原因：

| 原因 | 怎么办 |
|---|---|
| **没联网 / 网络慢** | 换个网络，或者挂梯子重试 |
| **公司/学校网络挡了** | 换成国内镜像（见下面） |
| **Python 版本太老** | 装 3.9 以上 |

**换国内镜像的办法**：按 `Win + R`，输入 `cmd`，回车。在弹出的黑窗口里粘贴这一行，回车：

```
python -m pip install pyscipopt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

装完再双击 `跑我.bat`。

---

## 如果窗口一闪就没了

说明 `.bat` 文件被杀毒软件拦了，或者路径里有特殊字符。

**替代办法（手动跑）**：

1. 按 `Win + R`
2. 输入 `cmd`，回车 → 弹出黑窗口
3. 输入下面这行（**注意 `cd /d` 后面是你的文件夹路径**），回车：

```
cd /d "C:\Users\yuche\Desktop\uav_stage0_frozen_example_cn\my_stage0_freeze"
```

4. 再输入这行，回车：

```
python 看懂求解器.py
```

---

## 如果输出的中文变成乱码

在 cmd 里先运行这一行，再跑脚本：

```
chcp 65001
```

## 进阶：用 VS Code 看代码（可选）

如果你想**看懂脚本在写什么**、或者自己改着玩，用编辑器比命令行舒服。

你电脑上似乎已经装了 VS Code。打开它，然后：

1. 菜单 **File → Open Folder**，选你的项目文件夹
2. 左边列表里点 `看懂求解器.py`
3. 右上角有个 **▷ 三角形按钮**，点它就运行
4. 底部会弹出终端显示输出

第一次打开 `.py` 文件时，VS Code 右下角可能提示你装 **Python 扩展** —— 点"安装"就行。

## 跑通之后，做这五个练习

打开 `看懂求解器.py`，找到这几行（大约在文件的三分之二处）：

```python
m.setPresolve(SCIP_PARAMSETTING.OFF)
m.setSeparating(SCIP_PARAMSETTING.OFF)
m.setHeuristics(SCIP_PARAMSETTING.OFF)
```

**每次只改一处，改完保存，再跑一遍，对比"一共开了多少个节点"这个数字。**

| # | 改什么 | 观察什么 |
|---|---|---|
| 1 | 把 `setSeparating` 那行前面加 `#`（注释掉） | 割平面开了，节点数变多还是变少？ |
| 2 | 把 `setHeuristics` 那行注释掉 | "全局下界"什么时候第一次出现？ |
| 3 | 把 `setPresolve` 那行注释掉 | 变量名还是 `t_x2` 吗？变量少了吗？ |
| 4 | **加一行** `m.setParam("branching/fullstrong/priority", 536870911)` | **节点数掉了多少？这就是「门 3」** |
| 5 | 把 `n = 12` 改成 `n = 40` | 树是不是爆炸了？ |

**第 4 个练习是重点。** 你用一行代码就完成了整个项目里最关键的那次测量。

## 名词解释（怕你卡在这儿）

| 你会看到 | 是什么 |
|---|---|
| **cmd / 命令提示符** | Windows 自带的黑窗口，用来打命令。`Win + R` → 输入 `cmd` → 回车 |
| **PATH** | Windows 的"到哪儿找程序"清单。不加进去，打 `python` 就会说"不是内部或外部命令" |
| **pip** | Python 的软件包安装工具。`pip install 某某` = 装某某 |
| **`.bat`** | Windows 批处理文件。就是一串命令写在文件里，双击一次全跑完 |
| **`.py`** | Python 脚本文件 |
| **IDE / 编辑器** | 写代码的软件。VS Code 是最常用的一个 |
| **终端 / terminal** | 和 cmd 差不多，编辑器内置的那个黑框 |
